| W6 query agent | same, §2 Step 8 | none (`query_agent/` does not exist) |

The design docs refer to themselves as `imp_docs/...`. That path does not exist; the files are in `docs/`.

So integration means, concretely:

1. Make the image pipeline **emit the contracts** the design defines: OKF claim files (W2 → W4), review-queue
   files, and a splat sidecar manifest (W2 → W5). §7 maps each field; §8 gives a working reference adapter.
2. Make the image pipeline's **outputs addressable from the graph**: stable IDs for evidence, regions and scenes, and
   one documented coordinate frame. See §5 and §7.
3. Expose the pipeline's **query and viewer services** to the query agent (W6). See §7.7.
4. Fix the **verified gaps** that would otherwise make a second scene silently reuse the first scene's artifacts or
   crash. See §9.

## 1. Where the image pipeline sits in the 8-step system

From `docs/cross_team_agentic_dev_plan.md` §2:

```
          text ──► [1 W1 text]  ─┐
        photos ──► [2 W2 image] ─┼─► OKF claim bundles ──► [4 W4 fusion] ──► [5 Neo4j] ──► [8 W6 query agent]
         video ──► [3 W3 video] ─┘                                               │               │
                       │  splat assets + sidecar manifest                         ▼               ▼
                       └────────────────────────────────────────────► [6/7 W5 :Scene per :Event] ─► viewer
```

Design principles that constrain the image pipeline's outputs:

* **Late fusion.** W2 never reads W1/W3 output and never resolves anything. It emits *claims* only.
* **Provenance.** Every fact must walk back `(:Entity)-[:RESOLVED_FROM]->(:Claim)-[:EXTRACTED_FROM]->(:Evidence)`.
  The image pipeline must therefore give each claim a stable pointer to its source photo.
* **Time intervals, not points.** Every claim/edge carries `t_start`/`t_end`. For photos this is **capture time**
  (see §7.8; it is not incident time).
* **Write ownership.** Only W4 writes `:Entity`, `:Event`, `:RESOLVED_FROM`. W5 writes `:Scene` and its links. W2 writes
  **files** only (OKF claims, review items, manifest), never Neo4j directly.

What W2 has already built goes beyond the design's Step 2: it also contains a text-query layer (SAM + CLIP regions
with 3D locations) and a WebGL viewer. Those map onto Steps 6–8 (the viewer W5/W6 need) and are the natural
"visual grounding" service for W6 (§7.7).

What the design asks of W2 that is **not built**: BLIP-style relational captioning that emits claims such as "knife on
floor near table" (`cross_team_agentic_dev_plan.md` §2 Step 2, §8). §7.1 shows how to emit valid image claims **now**
from the existing SAM+CLIP regions, without captioning.

## 5. Identifiers and coordinate frames (read before writing any join)

### 5.1 Image identifiers

| Name | Example | Where | Stable? |
|---|---|---|---|
| original filename | `IMG_0463.jpg` | `photos/`, `photos_corrected/`, COLMAP `images.txt` name, every lookup's `image`, `camera_poses.json` `image`, API `viewpoint_id` | yes: **use this as the join key** |
| nerfstudio frame | `images/frame_00007.jpg` | `transforms.json` `file_path`, lookup `frame_path` | per `ns-process-data` run only |
| COLMAP image id | `7` | `images.txt`, `transforms.json` `colmap_im_id` | per COLMAP run only |
| nerfstudio dataset index | `train[5]` | in-memory only (`render_query.find_camera`) | per training run only |

Join chain: `colmap_im_id` (transforms.json) ↔ `image_id` (images.txt) → `name` (= original filename).

Photos that COLMAP did not register have only the original filename; they appear only in `region_lookup_2d_only.json`
and `photo_labels.json`.

### 5.2 Coordinate frames

There are three 3D frames. Mixing them is the most likely integration bug.

| Frame | What lives there | Convert |
|---|---|---|
| COLMAP world (`raw`) | `sparse/0`, `sparse_txt`, `point3d_raw`, `eval/` tool outputs | – |
| nerfstudio applied frame | `sparse_pc.ply`, `transforms.json` poses | `applied_transform` from `transforms.json` |
| **splat frame (`final`)** | trained Gaussians, `splat.ply`, `point3d_final`, `camera_poses.json` | `p_final = (T @ [p_raw, 1]) * s` with `T`, `s` from that run's `dataparser_transforms.json` (`tag_regions.raw_to_final`) |

**Use the splat frame for everything the graph stores** (it is the frame the viewer renders), and always store the
`scene_id` (and so the `dataparser_transforms.json`) next to any coordinate. A coordinate is meaningless across
training runs: every `ns-train` writes its own `T`, `s`.

Camera conventions (three different ones; `extract_camera_poses.py` docstring has the derivation):

* COLMAP: world→camera `(qvec, tvec)`, OpenCV axes (+x right, +y down, +z forward). Centre `C = -Rᵀt`.
* nerfstudio / `transforms.json`: camera→world, OpenGL axes (+y up, −z forward): `R_nerf = R_cw · diag(1,−1,−1)`.
* gsplat.js viewer: +Z forward: `R_gsplat = (T[:3,:3] · R_nerf) · diag(−1,1,−1)`. Rotation gets no scale.

### 5.3 2D region frame

`bbox_resized` is `[x, y, w, h]` in pixels of the image resized so its long side is 1024 (`resized_wh`). To get pixels
in the upright full-resolution photo: multiply by `full_width / resized_wh[0]`. The upright photo is the one in
`photos_corrected/` (or the raw photo after `ImageOps.exif_transpose`).

### 5.4 Scale and units

**There is no metric scale.** COLMAP's scale is arbitrary and no scale bar or ground control is used anywhere in the
pipeline (`docs/methods_draft.md` §7). Splat-frame numbers are unitless. Never write a distance or size derived from
them into the graph as metres. Store `metric_scale: null`.

### 5.5 Getting a metric frame (optional, not wired in)

`pipelines/image/eval/` (env `crime-eval`) can estimate a Sim(3) from the COLMAP frame to a measured frame:

* ArUco markers: `detect_markers.py` → `triangulate_markers.py` → `marker_error.py` (writes `{"sim3": {"scale","R","t"}}`).
* Hand-picked point pairs: `landmark_align.py`.
* Known GT poses: `pose_error.py`.

These produce a Sim(3) **in the COLMAP frame**. To apply it to splat-frame points, first invert the dataparser
transform: with `T = [R_T | t_T]`, `p_raw = R_Tᵀ (p_final / s − t_T)` [VERIFIED on galanakis2021: `R_T` is orthonormal to 5e-8, and this inverse reproduces `point3d_raw` from `point3d_final` to 6e-8]. `eval/README.md` states
that none of these tools has yet been run on a real scene with real ground truth.

### 7.1 Image claims → OKF (W2 → W4) [PROPOSED mapping onto the DESIGN contract]

The design contract (`cross_team_agentic_dev_plan.md` §6) requires one markdown+YAML file per claim in
`okf/claims/image/`:

```yaml

source_id: <string>
raw_label: <string>
confidence_tier: sensor | visual | narrative

extracted_at: <ISO8601>
predicate: <optional>   target_claim_id: <optional>   t_start/t_end: <optional ISO8601>   feature_tube_id: <video only>
```

What an image claim **is**, given what exists: the pipeline has no captioner, so it cannot produce relational claims
on its own. It can produce **"this photo region depicts `<label>`" claims** by ranking SAM regions against a label
vocabulary with CLIP. Mapping:

| Contract field | Value for image claims | Source |
|---|---|---|
| `type` | `Claim` | constant |
| `id` [PROPOSED addition] | `claim_img_` + first 16 hex of sha1(`scene_id|image|mask_idx|label|lookup_sha`) | deterministic, so re-runs are idempotent (`MERGE`-safe) |
| `source_modality` | `image` | constant |
| `source_id` | `evidence:photo:<scene_id>:<original filename>` | §7.4; joins to `:Evidence.id` |
| `raw_label` | the vocabulary term that matched | §7.1.1 |
| `confidence_tier` | `visual` | constant (design) |
| `confidence` | `similarity` (raw CLIP cosine, 4 dp) | match dict; **uncalibrated** (§12.1) |
| `extracted_at` | UTC time of the adapter run | |
| `predicate`, `target_claim_id` | omitted | no relation extraction exists |
| `t_start` = `t_end` | EXIF `DateTimeOriginal` (+`OffsetTimeOriginal`) of the **raw** photo; omit both if absent | §7.8; `photos_corrected/` has no EXIF |
| `feature_tube_id` | never | video only |
| body | one sentence: region, image, rank, cosine, 3D location or not-localized message | |
| `x_image` | namespaced extension, §7.3 | |

#### 7.1.1 Where the label vocabulary comes from

Choose one and record it (suggested field `x_image.vocabulary_source`):

1. **Fixed forensic vocabulary** (default). The 8 terms the repo already validated in `demo_assets/query_summary.md`
   are `blood stain, body, evidence marker, floor, footprint, mannequin, shoe, weapon`. Extend from W1's entity taxonomy
   (`docs/phase1_text_pipeline.md` §3.1: PERSON, WEAPON, LOCATION, OBJECT ...) once it is final.
2. **Labels drawn from text claims** (`raw_label` of `okf/claims/text/*`). This turns the image pipeline into a visual
   grounding service for text entities and gives fusion strong alignment candidates, but it couples W2 to W1's output,
   which the late-fusion principle tries to avoid. If used, it must be recorded per claim, and W4 must not treat
   such an image claim as independent corroboration of the text claim that produced its label.

`top_k` per label: 3 is a reasonable start. Because similarity cannot tell present from absent objects, every label
produces `k` claims even if the object is not in the scene (verified: `"a car"` produces 3 claims on galanakis2021).
That is why §7.2 routes them all to review.

### 7.2 Review queue (shared contract) [PROPOSED behaviour, DESIGN format]

Design threshold for image claim extraction is **0.65** (`cross_team_agentic_dev_plan.md` §3). Observed CLIP cosines
for this pipeline are about 0.25–0.35, so **every image claim falls below threshold** and must also get an
`okf/review/` file. This is the correct outcome: the claim is kept (it is evidence), and a human confirms it before
fusion trusts it. Do not "fix" this by rescaling cosines into [0.65, 1]; that would hide the documented limitation.

ReviewItem written per claim (format from the design, §3):

```yaml
type: ReviewItem
stage: extraction
confidence: 0.2583
threshold: 0.65
reason: "Image claim confidence is a raw CLIP cosine; no threshold separates real from absent objects ..."
candidate_resolution: claim_img_08b3deb7819fcf64
claim_ids: [claim_img_08b3deb7819fcf64]
created_at: "2026-11-10T09:53:40Z"
resolved: false
---
Open IMG_0477.jpg and check bbox [0, 425, 171, 61] (in a [1024, 768] resized frame ...) for 'a car'.
```

Ways to legitimately raise image confidence later (none built): calibrate cosines against labelled regions
(`eval/score_queries.py` already scores query localisation against GT and reports false-positive rate on absent
queries); add `num_support_points` as a second signal (22 vs 1 separated the one present/absent pair tested; untested
beyond that); or add the designed BLIP captioning step.

Who writes what:


(`$c.x_image.point3d_splat_frame` is a list of 3 floats or null; null removes the property, which is fine.)

W5: register the reconstruction as a scene:

```cypher
MERGE (s:Scene {id: 'scene:image:' + $m.scene_id})
SET s.splat_uri = $m.splat_uri, s.splat_sha256 = $m.splat_sha256, s.source_modality = 'image',

    s.metric_scale = NULL, s.gaussian_count = $m.reconstruction.gaussian_count

MATCH (ev:Evidence {id: eid})
MERGE (s)-[:DERIVED_FROM]->(ev)
```

W5: after fusion, link the scene to entities that image claims from this scene helped resolve:

```cypher
MATCH (s:Scene {id: 'scene:image:' + $scene_id})
MATCH (e:Entity)-[:RESOLVED_FROM]->(c:Claim {source_modality: 'image', scene_id: $scene_id})
MERGE (s)-[:DEPICTS]->(e)
```

Constraint to add alongside `neo4j_schema.md`'s list: `CREATE CONSTRAINT evidence_id IF NOT EXISTS FOR (v:Evidence) REQUIRE v.id IS UNIQUE;`

`:Scene` vs action points: the schema expects one `:Scene` per `:Event`. A photo set is one static reconstruction of
the scene as documented after the incident, so it does not render a specific action point. Options for W5: link it
with `[:RENDERS]` to an "aftermath / scene documentation" `:Event`, or leave `action_point_id` null and use it as the
spatial backdrop for all events at that `:Location`. This is an open design decision for W5, not something W2 decides.

### 7.8 Time semantics (do not get this wrong)

* Crime-scene photos are taken **after** the incident. Their EXIF time is when the scene was documented, not when any
  event happened. W4 must not align photo claims onto the incident timeline as if they were event times; treat
  `t_start/t_end` on image claims as an upper bound ("the object was there by this time").
* EXIF time often has no timezone (`OffsetTimeOriginal` missing) and camera clocks drift. Record what is there; do not
  invent a timezone.
* `fix_exif_orientation.py` removes all EXIF (`corrected.save(dst)` at `scripts/fix_exif_orientation.py:50`)
  [VERIFIED with a synthetic JPEG: Orientation and DateTime both gone]. Read times from `photos/` only.
* Many datasets ship without EXIF. galanakis2021 has capture times on 3 of 30 photos [VERIFIED].

### 8.1 `emit_image_okf.py` (run in `crime-image-tag`, from the repo root)

```python
"""

+ a splat sidecar manifest (the W2 -> W4 and W2 -> W5 contracts in
docs/cross_team_agentic_dev_plan.md section 6).

Runs in the `crime-image-tag` env (needs open_clip via query_regions.py, PyYAML).

    python pipelines/image/integration/emit_image_okf.py \
      --scene-id galanakis2021 \
      --raw-photos-dir pipelines/image/data/galanakis2021/photos \
      --colmap-dir pipelines/image/data/galanakis2021/colmap \
      --lookup pipelines/image/query/region_lookup.json \
      --lookup-2d-only pipelines/image/query/region_lookup_2d_only.json \
      --dataparser-transforms outputs/colmap_pruned/splatfacto/2026-08-24_010039/dataparser_transforms.json \
      --checkpoint-config outputs/colmap_pruned/splatfacto/2026-08-24_010039/config.yml \
      --splat-ply pipelines/image/ui_web/export/splat.ply \
      --vocab "blood stain" "body" "evidence marker" "footprint" "shoe" "weapon" \
      --top-k-per-label 3 \
      --okf-root okf \
      --manifest-out okf_manifests/galanakis2021.splat_manifest.json
"""
from __future__ import annotations

import argparse
import datetime as dt
import hashlib
import json
import subprocess
import sys
from pathlib import Path

import yaml
from PIL import Image

REPO_ROOT = Path.cwd()
sys.path.insert(0, str(REPO_ROOT / "pipelines/image/scripts"))
import query_regions  # noqa: E402  -- reuse the real matching code, do not reimplement

IMAGE_CLAIM_THRESHOLD = 0.65  # cross_team_agentic_dev_plan.md section 3, "Image claim extraction"
CLIP_MODEL_ACTUAL = "open_clip ViT-B-32-quickgelu / openai"  # what tag_regions.py really loads


def sha256_file(p: Path, chunk: int = 1 << 20) -> str:
    h = hashlib.sha256()
    with open(p, "rb") as f:
        while b := f.read(chunk):
            h.update(b)
    return h.hexdigest()


def now_iso() -> str:
    return dt.datetime.now(dt.timezone.utc).replace(microsecond=0).isoformat().replace("+00:00", "Z")


def exif_capture_time(raw_photo: Path) -> str | None:
    """DateTimeOriginal (+ OffsetTimeOriginal if present) from the RAW photo.
    photos_corrected/ has NO EXIF (fix_exif_orientation.py drops it), so never read it there.
    Returns ISO8601, or None when the camera/dataset recorded no time."""
    try:
        exif = Image.open(raw_photo).getexif()
    except Exception:
        return None
    sub = exif.get_ifd(0x8769)
    raw = sub.get(0x9003) or exif.get(0x0132)  # DateTimeOriginal, else DateTime
    if not raw:
        return None
    try:
        t = dt.datetime.strptime(str(raw).strip(), "%Y:%m:%d %H:%M:%S")
    except ValueError:
        return None
    offset = sub.get(0x9011)  # OffsetTimeOriginal, e.g. "+08:00"
    return t.isoformat() + (str(offset) if offset else "")  # no offset -> naive local time, say so downstream


def evidence_id(scene_id: str, filename: str) -> str:
    return f"evidence:photo:{scene_id}:{filename}"


def claim_id(scene_id: str, rec: dict, label: str, lookup_sha: str) -> str:
    key = f"{scene_id}|{rec['image']}|{rec['mask_idx']}|{label}|{lookup_sha}"
    return "claim_img_" + hashlib.sha1(key.encode()).hexdigest()[:16]


def write_okf(path: Path, front: dict, body: str) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text("---\n" + yaml.safe_dump(front, sort_keys=False, allow_unicode=True) + "---\n" + body.rstrip() + "\n")


def ply_vertex_count(ply: Path) -> int | None:
    with open(ply, "rb") as f:
        for _ in range(64):
            line = f.readline().decode("ascii", "replace").strip()
            if line.startswith("element vertex"):
                return int(line.split()[-1])
            if line == "end_header":
                break
    return None


def colmap_version() -> str | None:
    try:
        out = subprocess.run(["colmap", "-h"], capture_output=True, text=True, timeout=30).stdout
        return out.splitlines()[0].strip() if out else None
    except Exception:
        return None


def main() -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("--scene-id", required=True)
    ap.add_argument("--raw-photos-dir", type=Path, required=True)
    ap.add_argument("--colmap-dir", type=Path, required=True)
    ap.add_argument("--lookup", type=Path, required=True)
    ap.add_argument("--lookup-2d-only", type=Path, default=None)
    ap.add_argument("--dataparser-transforms", type=Path, required=True)
    ap.add_argument("--checkpoint-config", type=Path, required=True)
    ap.add_argument("--splat-ply", type=Path, required=True)
    ap.add_argument("--vocab", nargs="+", required=True)
    ap.add_argument("--top-k-per-label", type=int, default=3)
    ap.add_argument("--okf-root", type=Path, required=True)
    ap.add_argument("--threshold", type=float, default=IMAGE_CLAIM_THRESHOLD)
    ap.add_argument("--manifest-out", type=Path, default=None, help="default: <splat>.manifest.json next to the .ply")
    args = ap.parse_args()

    scene = args.scene_id
    lookup_sha = sha256_file(args.lookup)[:16]
    extracted_at = now_iso()

    # --- evidence: every input photo, registered or not --------------------
    transforms = json.loads((args.colmap_dir / "transforms.json").read_text())
    registered_frames = {Path(f["file_path"]).name for f in transforms["frames"]}
    localized_recs = json.loads(args.lookup.read_text())["records"]
    registered_names = sorted({r["image"] for r in localized_recs})  # COLMAP image names (raw filenames)
    photos = sorted(p for p in args.raw_photos_dir.iterdir()
                    if p.suffix.lower() in {".jpg", ".jpeg", ".png", ".tif", ".tiff"})
    evidence = []
    for p in photos:
        evidence.append({
            "id": evidence_id(scene, p.name),
            "modality": "photo",
            "file_uri": str(p),
            "captured_at": exif_capture_time(p),
            "sha256": sha256_file(p),
            "registered_in_reconstruction": p.name in registered_names,
        })
    ev_by_name = {Path(e["file_uri"]).name: e for e in evidence}

    # --- claims: vocabulary term x top-k regions ---------------------------
    model, tokenizer = query_regions.build_clip_model()
    n_claims = n_review = 0
    for label in args.vocab:
        matches = query_regions.top_k_matches(label, args.lookup, args.lookup_2d_only,
                                              k=args.top_k_per_label, model=model, tokenizer=tokenizer)
        for rank, m in enumerate(matches, start=1):
            cid = claim_id(scene, m, label, lookup_sha)
            ev = ev_by_name.get(m["image"])
            t = ev["captured_at"] if ev else None
            front = {
                "type": "Claim",
                "id": cid,
                "source_modality": "image",
                "source_id": evidence_id(scene, m["image"]),
                "raw_label": label,
                "confidence_tier": "visual",
                "confidence": round(float(m["similarity"]), 4),
                "extracted_at": extracted_at,
            }
            if t:
                front["t_start"] = t
                front["t_end"] = t
            front["x_image"] = {  # proposed namespaced extension -- see INTEGRATION.md section 7.3
                "scene_id": scene,
                "confidence_kind": "clip_cosine_uncalibrated",
                "rank_for_label": rank,
                "region_id": f"{scene}:{m['image']}:{m['mask_idx']}",
                "image": m["image"],
                "frame_path": m.get("frame_path"),
                "mask_idx": m["mask_idx"],
                "bbox_resized_xywh": m["bbox_resized"],
                "resized_wh": m["resized_wh"],
                "localized_3d": bool(m["localized"]),
                "point3d_splat_frame": m.get("point3d_final"),
                "num_support_points": m.get("num_support_points"),
                "time_semantics": "photo_capture_time" if t else None,
                "clip_model": CLIP_MODEL_ACTUAL,
                "region_lookup_sha256_16": lookup_sha,
            }
            where = (f"3D location (splat frame) {[round(v, 4) for v in m['point3d_final']]} "
                     f"from {m.get('num_support_points')} COLMAP SIFT-track points"
                     if m["localized"] else query_regions.NOT_LOCALIZED_MESSAGE)
            body = (f"SAM region {m['mask_idx']} of photo {m['image']} is the #{rank} CLIP match for "
                    f"\"{label}\" (cosine {m['similarity']:.4f}, uncalibrated: present and absent objects "
                    f"score in the same 0.25-0.35 band on the reference scene). {where}.")
            write_okf(args.okf_root / "claims/image" / f"{cid}.md", front, body)
            n_claims += 1

            if front["confidence"] < args.threshold:
                rid = "review_" + cid
                review = {
                    "type": "ReviewItem",
                    "stage": "extraction",
                    "confidence": front["confidence"],
                    "threshold": args.threshold,
                    "reason": ("Image claim confidence is a raw CLIP cosine; no threshold separates real from "
                               "absent objects (phase2_decision.md). Human must confirm the region shows "
                               f"'{label}'."),
                    "candidate_resolution": cid,
                    "claim_ids": [cid],
                    "created_at": extracted_at,
                    "resolved": False,
                }
                rbody = (f"Open {m['image']} and check bbox {m['bbox_resized']} (in a {m['resized_wh']} "
                         f"resized frame; scale by original_width/{m['resized_wh'][0]}) for '{label}'.")
                write_okf(args.okf_root / "review" / f"{rid}.md", review, rbody)
                n_review += 1

    # --- splat sidecar manifest (W2 -> W5) ----------------------------------
    dp = json.loads(args.dataparser_transforms.read_text())
    times = sorted(e["captured_at"] for e in evidence if e["captured_at"] and e["registered_in_reconstruction"])
    manifest = {
        "type": "SplatManifest",
        "manifest_version": "0.1-proposed",
        "scene_id": scene,
        "splat_uri": str(args.splat_ply),
        "splat_sha256": sha256_file(args.splat_ply),
        "source_modality": "image",
        "t_start": times[0] if times else None,
        "t_end": times[-1] if times else None,
        "time_semantics": "range of photo capture times (post-incident documentation), not incident time",
        "frame_range": None,
        "action_point_id": None,
        "evidence_ids": [e["id"] for e in evidence if e["registered_in_reconstruction"]],
        "evidence_ids_not_in_reconstruction": [e["id"] for e in evidence if not e["registered_in_reconstruction"]],
        "evidence": evidence,
        "coordinate_frame": {
            "name": "nerfstudio_dataparser_frame",
            "from_colmap_world": "p_splat = (T @ [p_colmap, 1]) * scale",
            "dataparser_transform_3x4": dp["transform"],
            "dataparser_scale": dp["scale"],
            "metric_scale": None,
            "units": "arbitrary (no scale bar / ground control)",
        },
        "reconstruction": {
            "colmap_version": colmap_version(),
            "colmap_model": str(args.colmap_dir / "sparse/0"),
            "n_photos_input": len(evidence),
            "n_registered": len(registered_frames),
            "checkpoint_config": str(args.checkpoint_config),
            "method": "nerfstudio 1.1.5 splatfacto, 30k iters, pruned",
            "gaussian_count": ply_vertex_count(args.splat_ply),
        },
        "region_lookup": {"localized": str(args.lookup),
                          "unlocalized_2d_only": str(args.lookup_2d_only) if args.lookup_2d_only else None,
                          "clip_model": CLIP_MODEL_ACTUAL},
        "created_at": extracted_at,
    }
    man_path = args.manifest_out or args.splat_ply.with_name(args.splat_ply.stem + ".manifest.json")
    man_path.parent.mkdir(parents=True, exist_ok=True)
    man_path.write_text(json.dumps(manifest, indent=1))

    print(f"[emit_image_okf] {n_claims} claims, {n_review} review items, {len(evidence)} evidence records")
    print(f"[emit_image_okf] manifest: {man_path}")


if __name__ == "__main__":
    main()
```

### 8.2 `validate_okf.py` (any env with PyYAML)

```python
#!/usr/bin/env python3
"""Validate OKF Claim / ReviewItem files against the contract in
docs/cross_team_agentic_dev_plan.md section 6 (+ section 3 for ReviewItem).
Usage: python validate_okf.py okf/claims/image okf/review   -> exit 1 on any violation."""
import datetime as dt
import sys
from pathlib import Path

import yaml

CLAIM_REQUIRED = {"type": str, "source_modality": str, "source_id": str, "raw_label": str,
                  "confidence_tier": str, "confidence": (int, float), "extracted_at": (str, dt.datetime)}
CLAIM_OPTIONAL = {"predicate", "target_claim_id", "t_start", "t_end", "feature_tube_id"}
TIER_FOR = {"text": "narrative", "image": "visual", "video": "sensor"}
REVIEW_REQUIRED = {"type", "stage", "confidence", "threshold", "reason", "claim_ids", "created_at", "resolved"}


def parse(p: Path):
    t = p.read_text()
    if not t.startswith("---\n"):
        raise ValueError("no YAML frontmatter")
    _, fm, body = t.split("---\n", 2)
    return yaml.safe_load(fm), body


def iso(v) -> bool:
    if isinstance(v, (dt.datetime, dt.date)):
        return True
    try:
        dt.datetime.fromisoformat(str(v).replace("Z", "+00:00"))
        return True
    except ValueError:
        return False


def check(p: Path) -> list[str]:
    try:
        fm, body = parse(p)
    except Exception as e:
        return [f"unparseable: {e}"]
    errs = []
    if fm.get("type") == "Claim":
        for k, ty in CLAIM_REQUIRED.items():
            if k not in fm:
                errs.append(f"missing {k}")
            elif not isinstance(fm[k], ty):
                errs.append(f"{k} has type {type(fm[k]).__name__}")
        mod = fm.get("source_modality")
        if mod not in TIER_FOR:
            errs.append(f"source_modality {mod!r}")
        elif fm.get("confidence_tier") != TIER_FOR[mod]:
            errs.append(f"confidence_tier {fm.get('confidence_tier')!r} != {TIER_FOR[mod]!r} for {mod}")
        c = fm.get("confidence")
        if isinstance(c, (int, float)) and not 0.0 <= c <= 1.0:
            errs.append(f"confidence {c} outside [0,1]")
        for k in ("extracted_at", "t_start", "t_end"):
            if k in fm and fm[k] is not None and not iso(fm[k]):
                errs.append(f"{k} not ISO8601: {fm[k]!r}")
        if ("t_start" in fm) != ("t_end" in fm):
            errs.append("t_start/t_end must come together")
        if "feature_tube_id" in fm and mod != "video":
            errs.append("feature_tube_id is video-only")
        unknown = set(fm) - set(CLAIM_REQUIRED) - CLAIM_OPTIONAL - {"id"} - {k for k in fm if k.startswith("x_")}
        if unknown:
            errs.append(f"unknown top-level keys {sorted(unknown)} (put extensions under x_<modality>)")
        if not body.strip():
            errs.append("empty body (contract wants the supporting evidence text)")
    elif fm.get("type") == "ReviewItem":
        errs += [f"missing {k}" for k in REVIEW_REQUIRED - set(fm)]
        if fm.get("stage") not in {"extraction", "fusion"}:
            errs.append(f"stage {fm.get('stage')!r}")
        if not isinstance(fm.get("claim_ids"), list) or not fm.get("claim_ids"):
            errs.append("claim_ids must be a non-empty list")
    else:
        errs.append(f"type {fm.get('type')!r} is neither Claim nor ReviewItem")
    return errs


def main() -> int:
    n = bad = 0
    for root in sys.argv[1:]:
        for p in sorted(Path(root).rglob("*.md")):
            n += 1
            errs = check(p)
            if errs:
                bad += 1
                print(f"FAIL {p}: {'; '.join(errs)}")
    print(f"{n} files checked, {bad} failing")
    return 1 if bad or n == 0 else 0


if __name__ == "__main__":
    sys.exit(main())
```

Run: `python pipelines/shared/okf_schema/validate_okf.py okf/claims/image okf/review` (exit 1 on any failure or on zero
files). Wire it into the image pipeline's tests as the design requires (`cross_team_agentic_dev_plan.md` §7,

```python
def read_images_txt(path: Path) -> dict[int, Image]:
    images = {}
    lines = [l for l in path.read_text().splitlines() if not l.startswith("#")]
    while lines and not lines[-1].strip():
        lines.pop()
    for i in range(0, len(lines), 2):
        header = lines[i].split()
        image_id = int(header[0])
        qvec = np.array([float(x) for x in header[1:5]])
        tvec = np.array([float(x) for x in header[5:8]])
        camera_id = int(header[8])
        name = header[9]
        pts = lines[i + 1].split() if i + 1 < len(lines) else []
        vals = np.array([float(x) for x in pts]).reshape(-1, 3)
        images[image_id] = Image(image_id, qvec, tvec, camera_id, name, vals[:, :2], vals[:, 2].astype(np.int64))
    return images
```

## 12. Limitations that must be carried into the graph, not hidden

### 12.1 No similarity threshold
A deliberately absent object (`"a car"`) scored 0.2592; a present one (`"blood spatter"`) scored 0.3226. The system
always returns a top match, with nothing in the output that tells a real match from a wrong one
(`docs/phase2_decision.md`). Consequences for integration: image claims are always review-queued (§7.2); W6 must show
the `caveat`; fusion must not treat an image claim as `visual`-tier corroboration until a human has resolved its
ReviewItem.

### 12.2 Uneven 3D coverage
A region gets a 3D point only if SIFT tracked points fall inside it. Blank, low-texture or single-view surfaces get no
region. Absence of an image claim is not evidence of absence.

### 12.3 No metric scale (§5.4)

### 12.4 One validated scene
End-to-end verified only on galanakis2021 (20/30 registered). The second scene, `th_0085`, failed at COLMAP for a
diagnosed capture-protocol reason. Registration varies run to run (20–22/30 with COLMAP 3.9.1).

### 12.5 COLMAP 4.2.1 fallback risk
If a newer COLMAP is used, images registered only by its structure-less fallback are much more often grossly
mis-posed (GLMM OR about 79–117 on ETH3D, `eval/results/eth3d/RESULTS_v11.md`). Regions from such images would carry
wrong 3D points. Record the COLMAP version; prefer 3.9.1 until a pose check exists.

### 12.6 Viewer rendering artifact
gsplat.js packs covariances as half floats, so needle-shaped Gaussians render as spikes in 15 of 20 preset views.
nerfstudio's own renderer is clean (`ui_web/README.md`). Use `render_query.py` for evidential stills.
